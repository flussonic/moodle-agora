# An Agora broadcast in a course

For: the teacher — put an Agora broadcast activity into a course, enrol
learners and see who completed the session.

Next to this: [for the Moodle administrator](../admin/README.md) — connecting
the site to the Agora server; [for learners](../student/README.md) — how to
watch.

> The screenshots are taken on a Russian-language Moodle; the English interface
> carries the same forms in the same order. The site label on them is `stand`,
> so the names of the created streams start with it; your label will be your
> own and the prefix will change with it.

Three words you will meet below:

- **Stream (broadcast)** — a named video stream on the Agora server: the live
  signal and its recording. One stream, one course activity.
- **Stream template** — the set of settings every stream created from it
  receives: recording depth, thumbnail frames, quality. The Agora operator sets
  it; Moodle does not change the template.
- **Viewing ticket** — the short-lived permit Moodle issues to one learner for
  one stream. Without a ticket the Agora server serves no video. The ticket is
  issued automatically when the learner opens the activity.
