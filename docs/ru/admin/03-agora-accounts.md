Всё в этом разделе делает оператор в консоли Agora, один раз на сайт Moodle.

Плагин ходит на сервер Agora под тремя учётными записями с разными ролями.
Разделение не формальность: та, что выписывает билеты, не должна уметь ничего
менять, а билеты на вещание из браузера выписывает отдельная запись, чтобы
в журнале Agora видеть, где просмотр, а где публикация. Учётная запись
`superadmin` из раздела [Что понадобится](02-prerequisites.md) плагину не нужна
и в настройки Moodle не вводится: она нужна оператору один раз, чтобы завести
эти три записи в консоли.

| Роль | Что делает | Зачем плагину |
|---|---|---|
| `player` | выписывает и отзывает билеты на просмотр | пустить слушателя к видео и отобрать доступ при отчислении |
| `admin` | читает списки эфиров и шаблонов, состояния эфиров, историю просмотра, правила допуска, записи и экспорты | показать список эфиров в форме, бейдж состояния на карточке, посчитать минуты просмотра, собрать билет на запись с роликом |
| `player` (запись `publisher`) | выписывает билеты публикации для вещания из браузера по WHIP | вещание из браузера (сейчас скрыто, см. ниже): браузер преподавателя вещает в эфир по такому билету |

Первые две обязательны: без них не работает даже просмотр. Третья нужна
только для вещания из браузера; без неё блок «Как вещать» и публикация
энкодером по SRT работают как прежде. Роль у третьей записи та
же `player` — сервер Agora пока не различает виды допуска, плагин различает
их сам выделенной записью.

> **Вещание из браузера временно скрыто** (заморожено 2026-10-16): кнопки на
> странице элемента нет независимо от настройки, страница публикатора
> доступна только по прямому адресу `/mod/agora/publish.php?id=<элемент>`.
> Третью учётную запись можно не заводить, пока функция скрыта: её настройки
> (учётная запись publisher, билет публикации и адрес WHIP) тоже скрыты
> со [страницы настроек](06-settings.md).

Откройте раздел **Accounts** консоли Agora и нажмите **Add account**. Введите
логин, дважды пароль и выберите роль `player`.

![Создание учётной записи роли player](../../img/guide/02-agora-account-player.png)

Повторите для второй записи, выбрав роль `admin`.

![Создание учётной записи роли admin](../../img/guide/02-agora-account-admin.png)

Если планируете вещание из браузера (пока оно скрыто — см. заметку выше),
заведите и третью запись — снова роль
`player`, логин говорящий, например `lms-publisher`.

Логины берите говорящие — по ним в консоли будет видно, чьи это записи.

![Список учётных записей: служебные записи заведены](../../img/guide/02-agora-accounts.png)

Правила, которые стоит знать заранее:

- **На каждый сайт Moodle — своя тройка.** Две LMS не должны ходить под
  одной учётной записью.
- **Отключение или удаление учётной записи роли `player` отзывает все
  выписанные ею билеты.** Слушатели перестают смотреть немедленно.
- **Смена пароля билеты не трогает** — плагин просто войдёт заново. Пароли
  меняйте при смене администратора LMS.

Пароли этих записей понадобятся в разделе [Настройки сайта](06-settings.md):
сохраните их сразу.
