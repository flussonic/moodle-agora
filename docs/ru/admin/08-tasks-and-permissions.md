## Фоновые задачи

**Сервер → Запланированные задачи.** Плагин добавляет две задачи по расписанию.

**«Эфир Agora: фоновый проход»** — по умолчанию раз в 10 минут. Гасит истёкшие
билеты и удаляет их строки через сутки, считает длительность просмотра для
условия прохождения и удаляет эфиры, созданные из курсов, по наступившим срокам
удаления.

Прохождение по минутам задача делает в два шага. Сначала спрашивает историю
просмотра и сохраняет накопленные секунды: время считается от открытия плеера
до последнего обращения к серверу Agora, а минута, которую Agora ждёт перед
закрытием брошенной сессии, вычитается. Потом ставит отметки — всем парам
«слушатель и элемент», у которых порог набран, а отметки нет, в том числе тем,
у кого прошлый проход отметку не поставил. Журнал задачи — **Запланированные
задачи → Журналы**.

Ниже — все строки, которые пишут задачи плагина, в порядке прохода. Журнал
задач — по-английски, как у задач ядра Moodle: переводов у него нет, поэтому
перевод дан рядом.

**«Эфир Agora: фоновый проход»**

| Строка журнала (как в журнале) | Перевод | Что значит |
|---|---|---|
| `expired tickets closed: N` | погашено истёкших билетов: N | билеты, у которых вышел срок, помечены погашенными, их JWT стёрт |
| `closed ticket rows deleted: N` | удалено строк погашенных билетов: N | строки билетов старше суток после срока удалены |
| `no activities with a watching-time condition` | элементов с условием по длительности нет | считать нечего: ни у одного элемента нет условия «смотрел не меньше M минут» |
| `history window F-T is full (N sessions), splitting in half (эфир)` | окно истории F–T переполнено, делю пополам | в ответе истории 500 и больше склеенных сессий — окно спрашивается половинами |
| `viewing history unavailable (эфир, userid Y): код …` | история просмотра недоступна | отказ сервера Agora — или история не уместилась в 10 страниц, или сервер вернул тот же курсор страницы дважды (текст причины — в строке); счёт пары не трогается, граница опроса не двигается, отметки по уже сохранённым секундам ставятся |
| `activity X: pairs without an Agora user_id, history not asked: N; the next ticket of the pair restores it` | элемент X: пар без user_id в Agora, история не спрошена: N | у пары нет идентификатора в Agora (шаг обновления не смог его собрать: не было метки сайта или пользователь удалён); следующий билет пары его соберёт |
| `no sessions for user_id, but a live ticket exists: jti=… (эфир, userid Y)` | сессий по user_id нет, а живой билет есть | слушатель открыл страницу, но видео не играл |
| `pair (activity X, userid Y) skipped: …` | пара пропущена | сбой на одной паре; проход идёт дальше |
| `activity X: N sessions, S s counted, T s of idle time after the last request left out` | элемент X: N сессий, засчитано S с, вычтено T с простоя | сколько посчитано по истории и сколько простоя не пошло в зачёт |
| `activity X: completion is off in the course, N pairs reached the threshold, no marks set` | прохождение в курсе выключено, порог набрали N | отметки встанут после включения отслеживания |
| `completion mark (activity X, userid Y) not set: …` | отметка не поставлена | сбой на отметке одной пары; секунды сохранены |
| `activity X: completion marks not set for N pairs: …` | отметки не поставлены N парам | сбой, когда пары уже найдены (например, курс не читается) |
| `activity X: completion marks not set: …` | отметки элемента X не поставлены | сбой ещё до выборки пар |
| `watching-time completion marks set: N` | поставлено отметок по длительности: N | отметки встали |
| `threshold reached, activity waits for other completion conditions: K` | порог набран, элемент ждёт других условий | у элемента есть ещё условие, например «просмотрел элемент» |
| `threshold reached, learner not tracked (unenrolled or suspended), no mark: K` | порог набран, слушатель не отслеживается | отчисленному и приостановленному отметку не ставят |
| `completion marks failed: K; seconds are saved, the next pass retries` | не поставлено из-за отказа: K (по парам) | следующий проход повторит без запроса истории |
| `activities whose marks failed before the pairs were known: K; the next pass retries` | элементов, где отметки упали до выборки пар: K | число пар неизвестно; следующий проход повторит |
| `Agora user references forgotten after the tail window: N` | стёрто идентификаторов Agora после недели: N | `user_id` пары (с логином) стёрт через неделю после её последнего билета |
| `stream NAME could not be deleted: код …` | эфир не удалён | отложенное удаление наступило, а сервер Agora отказал; следующий проход повторит |
| `streams deleted by tombstones: N` | удалено эфиров по отложенного удалениям: N | эфиры удалённых из курса элементов удалены в Agora |

**«Эфир Agora: обновление состояний эфиров»** и одноразовые обновления

| Строка журнала (как в журнале) | Перевод | Что значит |
|---|---|---|
| `no activity streams, nothing to refresh` | эфиров элементов нет | элементов «Эфир Agora» на сайте нет; проход считается удачным |
| `stream states not refreshed: код …` | состояния не обновлены | отказ сервера Agora; прежние значения живут до конца окна свежести |
| `stream states refreshed: N, missing in Agora: M, no answer: K` | обновлено N, нет в Agora M, без ответа K | итог прохода; «нет в Agora» — эфир удалён оператором |
| `stream state NAME refreshed: состояние` | состояние эфира обновлено | одноразовая задача обновила одно протухшее значение |

**Обновление плагина** (`admin/cli/upgrade.php`, версия 2026092507), только если
такие строки есть:

| Строка вывода | Перевод | Что значит |
|---|---|---|
| `pair rows without tickets given an age: N, of them given user_id from the current username: K, left without user_id: L` | строкам пар без билетов дана давность: N, из них `user_id` по текущему логину: K, без `user_id`: L | у старых пар восстановлена давность; `user_id` собран по формуле `<метка сайта>:<id>:<логин>`; без метки сайта или у удалённого пользователя — не угадывается, и историю по такой паре задача не спросит |

Пару задача опрашивает и отмечает неделю после её последнего билета. Считается
это по записи пары в плагине, а не по билетам: погашенные билеты удаляются
через сутки. Через неделю `user_id` пары стирается; накопленные секунды
остаются. У удалённого пользователя строки пар удаляются сразу.

**«Эфир Agora: обновление состояний эфиров»** — по умолчанию раз в минуту.
Забирает у сервера Agora состояния всех эфиров, привязанных к элементам,
постраничными списками (по 100 за раз) и кладёт их в кэш. Из этого кэша боковая
колонка страницы элемента берёт бейджи и кадры соседних эфиров: сама она на
сервер Agora не ходит, и без этой задачи соседи остаются без бейджей и кадров
через три минуты. Итог каждого прохода лежит в настройках плагина — время,
число обновлённых эфиров и текст последней ошибки; их же читает проверка
«Agora: обновление состояний эфиров».

Эта же задача завершает эфиры по тишине: элемент в фазе «идёт», у которого
сигнал пропал дольше порога «Завершать эфир по тишине», она доводит до
завершения теми же действиями, что и кнопка «Завершить эфир» (стоп записи,
снятие публикации, фаза «завершён»), а неудавшееся ранее завершение
повторяет, пока оно не подтвердится. Подробности — в
[Настройки сайта → Завершение по тишине](06-settings.md#завершение-по-тишине).

Кроме них плагин ставит одноразовые задачи **«Эфир Agora: обновление состояния
эфира»**: когда состояние эфира в кэше протухло, страница курса отдаёт прежнее
значение, а обновление уходит в фон. Если cron не ходит, состояния на карточках
застревают — это первое, что стоит проверить при жалобе «бейдж врёт».

Страница самого элемента от cron не зависит: состояние своего эфира старше
15 секунд она берёт у сервера Agora сама — под замком на эфир, так что сервер
Agora получает не больше одного такого запроса на эфир за 15 секунд, сколько бы
слушателей ни пришло к началу. Открытая страница без живого плеера раз в
15–20 секунд спрашивает сайт внешней функцией `mod_agora_get_stream_state`
(права — как у страницы, сессию не продлевает) и сама меняет заглушку на
плеер. Сто таких открытых страниц — около 6 запросов в секунду к Moodle, каждый
из кэша; во время эфира страницы с плеером не спрашивают вовсе.

Отдельной настройки расписания у плагина нет — оно живёт только здесь.

## Права

Плагин добавляет четыре права.

| Право | Что даёт | Кому по умолчанию |
|---|---|---|
| `mod/agora:addinstance` | добавлять в курс элемент «Эфир Agora» | преподавателю с правом редактирования, управляющему |
| `mod/agora:view` | смотреть эфир | слушателю, преподавателю, управляющему |
| `mod/agora:comment` | писать комментарии под плеером | слушателю, преподавателю, управляющему |
| `mod/agora:broadcast` | вести эфир: блок «Как вещать» с ключом, кнопки «Начать эфир» и «Завершить эфир», публикатор из браузера (сейчас скрыт) | преподавателю с правом редактирования и без него, управляющему |

`mod/agora:broadcast` — право вести, а не право редактировать: преподаватель
без права редактирования курса вещает так же, как с ним. Каждая точка
(показ ключа, его смена, обе кнопки, билет публикации, страница публикатора)
проверяет это право отдельно: без него действие отвергается без единого
вызова в Agora, а блок и кнопки на странице не рисуются. Слушатель блок
«Как вещать» и ключ не видит никогда.

Сверх них плагин опирается на штатные права ядра: `moodle/comment:post` (писать
комментарий), `moodle/comment:view` (читать ленту) и `moodle/comment:delete`
(удалять чужие). Подробности — в разделе
[Комментарии под плеером](06-settings.md#комментарии-под-плеером).

Отдельного права «управлять подключением» у плагина нет: настройки сайта
доступны тем, кто администрирует сайт.
