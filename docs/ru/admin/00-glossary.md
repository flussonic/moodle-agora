Шесть слов, которые встретятся дальше.

- **Сервер Agora** — сервер корпоративного видео: принимает сигнал, раздаёт его
  зрителям и хранит запись.
- **Консоль Agora** — веб-интерфейс сервера Agora. В ней работает оператор:
  заводит эфиры, шаблоны и учётные записи. Консоль англоязычная, поэтому её
  разделы ниже названы так, как они подписаны на экране.
- **Эфир** — именованный поток видео на сервере Agora: живой сигнал и его
  запись. Один эфир — один элемент курса.
- **Шаблон эфира** — набор настроек, который получает каждый созданный по нему
  эфир: глубина записи, кадры для обложек, качество. Задаётся в консоли Agora,
  из Moodle не меняется.
- **Билет на просмотр** — короткоживущий допуск, который Moodle выписывает
  одному слушателю на один эфир. Без билета сервер Agora видео не отдаёт.
- **Учётная запись Agora** — логин с ролью в консоли Agora. Плагину нужны две
  служебные учётные записи (`player` и `admin`); оператору — одна своя с ролью
  `superadmin`, чтобы их завести и настроить сервер. Слушателям и
  преподавателям учётные записи Agora не нужны: они входят только в Moodle.
