# Видео в курсах Moodle: сервер Agora

Кому: администратору Moodle — подготовить сервер Agora, поставить плагин «Эфир
Agora», настроить связь и держать её в рабочем состоянии.

Соседние разделы: [преподавателю](../teacher/README.md) — как добавить эфир в
курс; [слушателю](../student/README.md) — как смотреть.

Читать по порядку: каждая тема опирается на предыдущую.

> На снимках метка сайта — `stand`, поэтому имена созданных эфиров начинаются
> с неё; у вас метка будет своя, и префикс имён изменится вместе с ней.
