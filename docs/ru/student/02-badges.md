# Бейджи и заглушки

Кому: слушателю.

Темы раздела: [Как открыть эфир](01-open.md) · **Бейджи и заглушки** · [Страница эфира](03-broadcast-page.md) · [Запись после эфира](04-recording.md) · [Почему может не играть](05-not-playing.md) · [Где смотреть своё прохождение](06-completion.md)

---

Бейдж рядом с именем элемента говорит, что там сейчас.

| Бейдж | Что это значит | Что будет на странице |
|---|---|---|
| **Запланирован** | преподаватель готовит эфир, слушатели ещё не допущены | «Эфир ещё не начался» |
| **В эфире** | занятие идёт прямо сейчас | плеер эфира |
| **Сигнал пропал** | сигнал прервался меньше трёх минут назад | «Сигнал пропал, эфир скоро продолжится»; если запись есть — переход к ней |
| **Завершён** | занятие закончилось, запись готовится | «Запись скоро появится»; когда ролик готов — плеер записи |
| **Запись** | занятие закончилось, запись есть | плеер записи |
| **Ещё не начался** | эфира ещё не было | «Эфир ещё не начался» |
| **Без записи** | занятие закончилось, а запись не велась | «Запись этого эфира не велась» |
| **Состояние неизвестно** | сайт не смог узнать состояние эфира | код причины; скажите преподавателю |

Бейджи «Запланирован» и «Завершён» живут у элементов, эфиры которых
преподаватель ведёт сам: сигнал там не включает эфир для слушателей, а после
завершения эфир не возвращается. У остальных элементов бейдж читается из
состояния эфира, как в таблице выше.

На странице курса бейдж обновляется не чаще раза в минуту: отставание до
минуты — норма, это не поломка. Страница самого занятия узнаёт состояние
свежим — не старше 15 секунд, а открытая заглушка «Эфир ещё не начался» сама
сменится плеером, когда эфир пойдёт (см. [Страница эфира](03-broadcast-page.md)).

![Страница элемента: эфир идёт](../../img/guide/06-student-live.png)

![Страница элемента: эфир ещё не начался](../../img/guide/06-student-notstarted.png)

Одно исключение из «ещё не начался»: бывают эфиры, которые запускаются по
запросу зрителя. У такого заглушки нет — сразу открывается плеер с подписью
«эфир запустится по вашему запросу, подождите несколько секунд».
