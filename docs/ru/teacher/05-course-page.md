Готовый курс: у каждого элемента бейдж состояния и, если у эфира настроены
кадры, обложка.

![Страница курса с карточками эфиров](../../img/guide/05-course-cards.png)

| Состояние эфира | Бейдж |
|---|---|
| Идёт | «В эфире» |
| Сигнал пропал меньше 3 минут назад | «Сигнал пропал» |
| Закончился, запись есть | «Запись» |
| Ещё не начинался | «Ещё не начался» |
| Закончился, записи нет | «Без записи» |
| Получить состояние не удалось | «Состояние неизвестно» |

Состояние обновляется не чаще раза в минуту: отставание до минуты — норма.
