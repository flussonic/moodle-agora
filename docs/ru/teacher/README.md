# Эфир Agora в курсе

Кому: преподавателю — поставить в курс элемент «Эфир Agora», записать на курс
слушателей и посмотреть, кто занятие прошёл.

Соседние разделы: [администратору Moodle](../admin/README.md) — подключение
сайта к серверу Agora; [слушателю](../student/README.md) — как смотреть.

> На снимках метка сайта — `stand`, поэтому имена созданных эфиров начинаются
> с неё; у вас метка будет своя, и префикс имён изменится вместе с ней.

Три слова, которые встретятся дальше:

- **Эфир** — именованный поток видео на сервере Agora: живой сигнал и его
  запись. Один эфир — один элемент курса.
- **Шаблон эфира** — набор настроек, который получает каждый созданный по нему
  эфир: глубина записи, кадры для обложек, качество. Задаёт его оператор Agora,
  из Moodle шаблон не меняется.
- **Билет на просмотр** — короткоживущий допуск, который Moodle выписывает
  одному слушателю на один эфир. Без билета сервер Agora видео не отдаёт. Билет
  выписывается сам, когда слушатель открывает элемент.
