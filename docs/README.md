# mod_agora documentation

The Agora broadcast plugin shows an Agora live stream and its recording right
inside a Moodle course. The documentation is laid out by role and by language:
one topic, one file, with the section index giving the reading order.

| Role | English | Русский |
|---|---|---|
| Moodle administrator | [en/admin](en/admin/README.md) | [ru/admin](ru/admin/README.md) |
| Teacher | [en/teacher](en/teacher/README.md) | [ru/teacher](ru/teacher/README.md) |
| Learner | [en/student](en/student/README.md) | [ru/student](ru/student/README.md) |

Language indexes: [English](en/README.md) · [русский](ru/README.md).

The screenshots are shared by every document and live in `img/guide/`.
